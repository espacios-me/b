================================================================================
   BOTSPACE DASHBOARD - DEPLOYMENT RUNBOOK (WORKERS-FIRST SOURCE OF TRUTH)
================================================================================

PROJECT: BotSpace Dashboard
TARGET DOMAIN: espacios.me/botspace
DEPLOYMENT PLATFORM: Cloudflare Workers (with Wrangler static assets)
REPOSITORY: GitHub (botspace-dashboard)

================================================================================
1) PRODUCTION MODEL DECISION
================================================================================

This project is standardized on a single production model:

- Workers-first ✅
- Pages-first ❌ (removed from runbook to avoid overlap and split ownership)

Source of truth files:
- worker.js
- wrangler.toml
- .github/workflows/deploy-worker.yml

================================================================================
2) REQUIRED GITHUB SECRETS
================================================================================

- CLOUDFLARE_API_TOKEN
- CLOUDFLARE_ACCOUNT_ID

Optional app/runtime secrets should be managed in Cloudflare Worker settings.

================================================================================
3) CI/CD WORKFLOW
================================================================================

GitHub Actions workflow: `.github/workflows/deploy-worker.yml`

On push to `main` (or manual dispatch), the workflow:
1. Installs dependencies with pnpm
2. Runs `pnpm check`
3. Runs `pnpm build` to produce static frontend in `dist/public`
4. Runs `wrangler deploy`

`wrangler deploy` uses `wrangler.toml`:
- main = worker.js
- assets.directory = dist/public
- route = espacios.me/botspace*

================================================================================
4) ROUTING OWNERSHIP
================================================================================

The Worker owns `/botspace` route handling:
- `/bot` and `/bot/` redirect to `/botspace`
- `/botspace` and `/botspace/` return SPA shell (`index.html`)
- `/botspace/*` serves files from the Wrangler ASSETS binding
- Paths outside `/botspace` return 404

================================================================================
5) POST-DEPLOY VERIFICATION
================================================================================

- Open https://espacios.me/botspace and confirm the app loads.
- Confirm static assets load with 200 responses under `/botspace/assets/*`.
- Confirm legacy redirect: `/bot` -> `/botspace`.
- Confirm non-owned paths are not handled by this Worker.
